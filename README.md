# 🚗 EQUIPO ÉLITE - Valet Parking System

Sistema profesional de gestión de estacionamiento con control de valets, mapa interactivo y sincronización en tiempo real.

## ✨ Características

- 🗺️ **Mapa interactivo** del estacionamiento con 66 espacios
- 👥 **Control de personal** con registro de descansos
- 🔄 **Sincronización en tiempo real** con Firebase
- 📊 **Reportes Excel** automatizados
- 🎨 **Modo claro/oscuro** y modo Kiosco
- 🦁 **Avatares personalizados** para cada valet

## 🛠️ Tecnologías

- HTML5, CSS3, JavaScript Vanilla
- Firebase Realtime Database
- SheetJS para exportación Excel
- Material Design Icons
